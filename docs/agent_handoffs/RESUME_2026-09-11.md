## Rebuild on any Linux box or cloud session (≈10 min + downloads)

```bash
git clone https://github.com/scottmcconnell1-bot/liberty-basketball-analysis.git && cd liberty-basketball-analysis
git switch claude/e2e-suite                      # tip of the stack; contains #139 + #140 too
uv python install 3.13 && "$(uv python find 3.13)" -m venv .venv
.venv/bin/python -m pip install -U pip && .venv/bin/python -m pip install -r requirements.txt
# CV stack (CPU) — optional but needed for real analysis:
.venv/bin/python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -r requirements.docker.txt
git lfs install --local && git lfs pull --include="models/*.pt,data/videos/Q1_snippet.mp4,videos/Q1.mp4"
cp .env.example .env && sed -i "s/^SECRET_KEY=.*/SECRET_KEY=$(python3 -c 'import secrets;print(secrets.token_hex(32))')/" .env
.venv/bin/python -m pytest tests/ -q               # expect 663 passed, 29 skipped
bash scripts/run_e2e_live.sh                       # proves the production path end to end
```
Run the app on loopback only (auth is a no-op): see LOCAL_STANDUP §2 "Run it" for the
gunicorn launcher; never `python app.py` / `launch_liberty.py` on a box with real athlete data.
