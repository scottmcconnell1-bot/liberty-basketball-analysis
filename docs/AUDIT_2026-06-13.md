## 3. Ball Detection — Critical Finding

**This is the most important finding in this audit.**

From `experiments/detector_audit_top20/AUDIT_RESULTS.md`:
- **Detector v14: 0/20 precision.** Zero basketball detections in the top 20 results.
- The detector was fine-tuned on only 5 images, had mAP=0 across 15 epochs.

**Implication:** The ball detection subsystem does NOT work. Any features relying on ball detection (shot detection, possession tracking, play recognition) are built on a non-functional foundation.

**Recommended path:**
1. Audit the full detector training pipeline (data → labels → training → evaluation)
2. Establish a proper benchmark dataset with verified labels
3. Define acceptance criteria (e.g., precision > 80%, recall > 70% on held-out test set)
4. Rebuild detector from evidence, not assumptions

## 6. Summary

### What's Good
- Blueprint-based Flask architecture is clean and well-organized
- 16 test files provide a safety net
- Evidence protocol and verified facts docs show good engineering discipline
- Docker deployment infrastructure is in place
- The cleanup commits (removing 85+ generated files, moving experiments) were well-executed

### Priority Fixes
1. **Ball detection rebuild** — Current detector is non-functional (0/20 precision). This is the single biggest technical risk.
2. **Add `.gitignore`** — Prevent accidental commits of DB and generated files
3. **Verify `game_id` types** — Check if the TEXT vs INTEGER mismatch from main branch exists on jason
4. **Update IMPLEMENTATION_PLAN.md** — Mark phases with evidence-based status, not claims
5. **Dataset governance** — Platform-independent paths, label quality validation
6. **Secrets management** — Move hardcoded secrets to environment variables

### Bottom Line
The jason-5-may-updates branch is a mature Flask application with good architecture. The critical gap is the ball detection subsystem, which has been audited and found non-functional. Everything downstream of ball detection (shot detection, play recognition, possession tracking) needs to be rebuilt on a verified foundation. Don't trust any metrics or features that depend on the current detector.
