## What was not verified

- **PowerShell:** pwsh is not installed here, so neither `daily_git_save.ps1` nor `watchdog_teach_loop.ps1` was executed. What was verified:
  - The staging logic now lives in `git_save_select.py`, and tests run it against real git in a temp repo.
  - Those tests stage with the same git command line the .ps1 uses: `git reset -q`, then `git --literal-pathspecs add --pathspec-from-file=<file> --pathspec-file-nul`.
  - Tests check the .ps1 text: it no longer runs `add -A`, it resets before calling the helper, and the watchdog checks both markers with `exit 0` before `start_hoops_teach_detached.py`.
  - Still unchecked are Windows-specific behaviours: `GetTempFileName()`, `py -3.12`, and argument quoting for a temp path that contains spaces.
- **Real data:** no script was run against the live DB or real repo data.
- **Tracked files and history:** `tag-exports/_chrome_ls_q2` is still tracked and in history. `.gitignore` now ignores it, but the owner has to run `git rm --cached` and purge the history.
