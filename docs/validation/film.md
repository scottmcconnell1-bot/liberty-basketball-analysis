## Notes

- There is no schema change. Auto-accepted rows are identified by `review_notes = 'Auto-accepted (high confidence)'` with no `reviewed_by_user_id`. That is the note `auto_accept_high_confidence_events` already wrote; it is now a named constant.
- Film Tool teach grading of AI rows (corrected/rejected with the `Film Tool teach` note and no reviewer) is re-derived from the kept manual tag rows on every rebuild, so it counts as machine output. The manual tag rows themselves are never touched by a rebuild.
- AI rows keyed to another analysis key but sharing the relational game (legacy data) are no longer deleted by a rebuild of this key.
