# Basketball Evidence Protocol V1

Purpose

Prevent unsupported claims and make analysis outputs auditable.

## Required Structure

## SOURCE EVIDENCE

## VERIFICATION STATUS

OBSERVED | UNVERIFIED

## OBSERVATIONS

## DERIVED FACTS

## INTERPRETATION (OPTIONAL)

## OUTPUT TYPE

REPORT | DECISION | BLOCKER | QUESTION

## Rules

1. No derived fact without source evidence.

2. OBSERVED may only be used when evidence was directly inspected.

3. Interpretations must not be reported as facts.

4. Decisions must be supported by derived facts.

5. If evidence was not inspected, status must be UNVERIFIED.

## Violation Types

V1 Missing source evidence

V2 Unsupported derived fact

V3 Incorrect fact

V4 Decision without support

V5 Claimed verification not performed

V6 Missing output type

V7 Interpretation presented as fact
