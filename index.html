Liberty Basketball Analysis

Project GitHub Repository

Overview

This is a Flask‑based basketball operations app for Liberty that combines scheduling, games, sources, video upload/review, manual tagging, AI‑assisted event generation, practice planning, debugging, and lightweight local resource monitoring.

Key Features

  • Schedule and season management (CRUD)
  • Games and source tracking (manual + NFHS)
  • Film workflow: upload, tagging, bookmarks, AI‑generated events
  • Practice workflows: plans, coach notes, AI notes, summaries
  • Debug & issue reporting: in‑page drawer, issue log, app logs, AI‑failure visibility
  • Runtime telemetry: CPU, memory, GPU, live power data (when exposed)

Quick Start (local)

# Windows: double‑click Start Liberty.bat
# Linux/macOS:
bash scripts/launch_liberty.sh

Or use the setup TUI:

python3 scripts/setup_project.py
