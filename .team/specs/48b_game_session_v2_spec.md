- S3 Clock state per second. Home: d = previous clock - this clock; stop if |d| < 0.05; run if 0.5 <= d <= 2.05; else unknown. Away_adrian: both mss: stop if same seconds, run if seconds = previous -1 or -2 (mod 60); sst: run if read2 is sst and differs from read, stop if same as previous sst reading. - S4 Timeout and break timers (home only). The clock leaves value P by > 20 s, then within 130 samples comes back within 3 s of P and the next 3 legal reads stay within 6 s of P -> the samples in between become None (bridged, not a reset) (session_v3.bridge_excursions). This is Scott's timeout fact.
- S5 Segment boundaries. Held zero: home = clock 0 and read2 parses to 0 or None; away_adrian = sst, tenths 0, read2 0 or None; a zero hold is >= 3 zero samples with at most 2 stray reads in a row inside it (session_v2.zero_ends). Reset: home = clock jumps up >= 30 s over the last known value and the next 3 legal reads (within 6 samples) are within 5 s of the new value; away_adrian = sst -> mss with the next 3 samples mss (session_v3.resets_full / resets_partial). The film is cut into segments at every held zero and reset.
- S6 Period or not. Stoppage = run then stop lasting >= 5 samples. Tip = first run sample in the segment; start value = highest legal clock among samples max(segment start, tip-8) .. tip inclusive (home). A segment with no tip is skipped. Per segment, in film order: >= 3 stoppages -> period; 0 -> timer (not a period); 1-2 -> halftime (not a period) if it comes right after a game's 2nd period, else a period if its start value is within 2 s of L, else (no L, partial board) a period only right after the 3rd. L = most common start value (rounded to 30 s) of segments with >= 3 stoppages; None on partial boards. A new game starts when the next tip is > 8 min after the last period end (count back to 0). No period at all -> session.json with "error": "no periods" and exit non-zero -> stop for Scott.
- S7 Session. Period interval = tip time - 2.0 s to (segment ends at a held zero: the first zero sample + 3.0 s; otherwise: the last run sample + 3.0 s). V10 FT window after a held zero: from the interval end to min(end of the zero hold, zero + 90 s), FT-flagged moments only. Output keys: L, periods (start_ms, end_ms, stops, end "z"/"r"/"end", n_in_game), intervals, ft_windows, error - exactly as design48b/reference/session_v3_*.json.

## A. STEPS IN PLAIN WORDS
1. Find the dark scoreboard box, decide which board it is, and cut out only the clock strip.
2. Read the clock every second, plus a second look half a second later.
3. Mark each second as clock running, clock stopped, or unknown.
4. Take out timeout timers: the clock jumps away and comes back to the same game time.
5. Cut the film at every quarter end (clock held at zero) and every reset (clock jumps back up and stays).
6. A piece where the clock stops and starts at least 3 times is a real quarter. A piece that runs straight down is a timer (pre-game, halftime, between games). Pieces with 1-2 stops: halftime if right after the 2nd quarter, otherwise a quarter if it starts at the usual quarter length.
7. Game time = each quarter from 2 s before the clock first runs to 3 s after it hits zero, plus the free-throw window. Everything else is dropped before any make/miss step.
