## 4. Frame mapping (offsets, not absolute frames)

- A saved track's `ball`/`bodd` entries are `[index, x, y]` where `index` is an **OFFSET from the tag frame**, not an absolute frame.
- **Absolute frame** = `round(t_ms / 1000 * fps) + index`, exactly as `peak_from_track` does (`measure_net_moved.py:155-175`, line 164).
- The anchor frame is the output of `peak_from_track(track, t, fps)` — the rule's own crossing frame when there is one (reason `"crossing"`), else the closest-ball frame (`"no_crossing_closest_ball"`). **Import and call that function; do not re-derive it.**

## 8. Candidates kept per frame

For every frame in the shot's frame range:
- Run the v6 model on the crop (per §2).
- Keep **ALL** candidates where `class_name == 'basketball'` and `confidence >= 0.28` (the fixed confidence from §2). **Do not apply v6_ball's single-pick, its 220 px box filter, or its continuity weight — D1 keeps every detection and lets the arc choose.**
- **Near-hoop zone filter** (fixed in advance, must reach below 180 px for the rule's measures at `ai_bridge.py:1208` and deep points at `ai_bridge.py:1164, 1273`): keep only those whose centre satisfies
  - horizontally: `abs(x_center - hoop_x) <= 3.0 * hoop_w` (within 3 hoop widths of the grouped hoop centre)
  - vertically: `hoop_y - 4.0 * hoop_w <= y_center <= hoop_y + 300` px (from 4 hoop widths above the rim down to 300 px below it)
  - no pixel colour, no net box.
- **Cap**: if more than 3 candidates survive in a frame, keep only the **top 3 by confidence** (Scott's pasted advice). **Report** the number of frames where >3 candidates existed before capping.

## 9. Arc model (fixed in advance, no tuning after seeing results)

- **Model**: RANSAC on **real candidate points only** (no interpolation, no made-up points, no ByteTrack/DeepSORT — banned).
- **Fixed hyperparameters**:
  - Minimum points to attempt a fit: **4** for before-anchor (3 for parabola + 1 for RANSAC consensus), **3** for after-anchor.
  - Maximum residual for an inlier: **0.15 * hoop_w** pixels (inlier residual scales with hoop width; Adrian grouped hoop_w is 70–116 px, Notus 51–75 px).
  - RANSAC iterations: **100**.
  - Random seed: **42** (fixed).
- **Two windows, choose don't replace the whole list** (v1 replaced the whole saved ball list with the before-anchor inliers; that deletes the points through the net that the rule needs — 180 px measure, column, drift — so it would break every make):
  - **a. BEFORE the anchor (free flight)**: frames `anchor-15 .. anchor`, RANSAC parabola in time for y (a > 0, y down) and line in time for x, min 4 points, 100 iterations, seed 42, residual 0.15 * hoop_w.
  - **b. AFTER the anchor (in the net, not free flight)**: frames `anchor+1 .. anchor+12`, RANSAC **straight line in time for x AND for y** (no direction constraint, so a ball that comes back up is kept as it is), min 3 points, same iterations, seed and residual.
  - **c. In every frame of both windows that has an inlier**, the inlier **replaces the saved point for that frame** (add it if the saved list had no point there — it is a real detection). Frames with no inlier, and all frames outside the two windows, **keep the saved point unchanged**. `bodd` is **never changed**.
  - **d. Before any of this runs**, the script proves the no-op: with the saved lists untouched, the Stage A copy with every switch off gives the same verdict as the rule on all 140 (Stage A already showed 140/140). If not identical, stop.
- **One chosen point per frame at most**: from the inliers, pick at most one candidate per frame (the inlier closest to the fitted curve at that frame's t).
