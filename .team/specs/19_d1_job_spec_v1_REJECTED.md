## 4. Candidates kept per frame

For every frame in the shot's frame range:
- Run the v6 model on the frame.
- Keep **ALL** detections where `class_name == 'basketball'` and `confidence >= 0.25` (the fixed confidence from §2).
- **Near-hoop zone filter** (the same zone the v6 rule already reads — BINDING NOTE e): keep only those whose centre satisfies
  - horizontally: `abs(x_center - hoop_x) <= 3.0 * hoop_w`  (within 3 hoop widths of the grouped hoop centre)
  - vertically: `y_center <= hoop_y + 180 * scale_y`  (from above the rim down to 180 px below it; `scale_y` from the track's `_court_scale_y`, default 1.0)
  - no pixel colour, no net box.
- **Cap**: if more than 3 candidates survive in a frame, keep only the **top 3 by confidence** (Scott's pasted advice). **Report** the number of frames where >3 candidates existed before capping.

## 5. Arc model (fixed in advance, no tuning after seeing results)

- **Model**: parabola in frame-time for y, straight line in frame-time for x:
  - `y(t) = a * t^2 + b * t + c`  (image coordinates, y down)
  - `x(t) = m * t + k`
- **Fitting**: RANSAC on the **real candidate points only** (no interpolation, no made-up points, no ByteTrack/DeepSORT — banned).
- **Fixed hyperparameters**:
  - Minimum points to attempt a fit: **4** (3 for parabola + 1 for RANSAC consensus).
  - Maximum residual for an inlier: **0.15 * hoop_w** pixels (scales with hoop width so 720p and 1080p are comparable; grouped hoop_w is 90–110 px, so ~13–16 px).
  - RANSAC iterations: **100**.
  - Random seed: **42** (fixed).
  - Time window: **15 frames before the anchor frame** (≈0.6 s at 25 fps). The anchor frame is the rule's own crossing frame (`cross_idx` from the UNCHANGED rule) if a crossing was found, otherwise the saved `peak_frame` from the track's `peak_reason` (never the truth label).
  - Constraint: `a > 0` in image y-down coordinates (falling trajectory).
- **One chosen point per frame at most**: from the inliers, pick at most one candidate per frame (the inlier closest to the fitted parabola at that frame's t).

## 6. Replacement and verdict

- The chosen inlier points (one per frame, in time order) **replace the saved `ball` list** for that shot.
- Everything else in the saved track (`bodd`, `hoop`, scales, `peak_frame`, `peak_reason`, etc.) **stays exactly as saved**.
- The modified track then goes through the **UNCHANGED rule** — the Stage A copy (`.team/shot_detectors/small_fixes_v6_copy.py`) with **every switch OFF** (A7, A8, A4, C4 all `False`). No other logic changes.

**Flags** (mutually exclusive per frame):
